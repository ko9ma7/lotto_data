# 로또 나침반 45

역대 로또 6/45 데이터를 탐색하고, 조건별 번호 조합을 만들고, 과거 당첨번호와 선택 번호의 형태를 비교하는 정적 웹앱입니다.

## 주요 기능

- 완전 무작위, 누적 균형, 최근 흐름, 장기 미출현, 데이터 혼합 조합
- 포함·제외 번호, 홀짝, 합계 조건
- 합계·홀짝·고저·연속수·AC와 과거 최대 일치 분석
- 최근 회차와 역대 당첨번호 검색
- 과거 1등 판매점 기록 지도와 검색
- 생성 이력 및 즐겨찾기 조합의 브라우저 `localStorage` 저장
- 기록 JSON 백업·복원, 번호 이미지 저장
- 반응형 화면, 다크 모드, 키보드 포커스, 동작 줄이기 설정 지원

## 중요한 안내

로또 추첨은 독립적인 무작위 사건입니다. 이 앱의 빈도, 미출현 기간, 형태 점수와 생성 방식은 다음 당첨번호를 예측하거나 당첨 확률을 높이지 않습니다. 데이터 탐색과 오락 목적으로만 사용하세요.

개인 기록은 서버로 전송하지 않고 현재 브라우저에만 저장합니다. 브라우저 데이터가 지워지면 기록도 사라질 수 있으므로 필요한 경우 백업 파일을 이용하세요.

## 실행

별도 빌드 없이 정적 파일을 제공합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 데이터 갱신

`.github/workflows/update-lotto.yml`이 `update_data.js`를 실행해 `lotto_history_data.js`와 `lotto_data.js`를 갱신합니다. 판매점 주소 좌표 변환에는 저장소 비밀값 `KAKAO_REST_API_KEY`가 필요합니다.

## 테스트

```bash
node --test tests/predict.test.cjs
```
